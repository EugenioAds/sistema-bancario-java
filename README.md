# 💰 Sistema Bancário em Java

Este projeto está sendo desenvolvido com o objetivo de praticar os principais conceitos de Programação Orientada a Objetos (POO) utilizando Java.

Além de reforçar os conhecimentos adquiridos durante a graduação em Ciência da Computação, o projeto também faz parte da construção do meu portfólio para ingressar na área de desenvolvimento de software.

## 🚀 Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub

## 📂 Estrutura do projeto

```
src
├── application
│   └── Main.java
├── entities
│   └── Conta.java
├── services
│   └── Banco.java
├── exceptions
└── resources
```

## ✅ Funcionalidades implementadas

- Cadastro de contas
- Depósito
- Saque
- Consulta de saldo
- Gerenciamento de múltiplas contas utilizando `ArrayList`
- Menu interativo via terminal
- Regras básicas de validação para depósito e saque

## 📚 Conceitos praticados

- Programação Orientada a Objetos (POO)
- Classes e Objetos
- Encapsulamento
- Construtores
- Métodos
- Getters
- Coleções (`ArrayList`)
- Estruturas de repetição (`do-while`)
- Estruturas de decisão (`switch-case`)
- Organização em pacotes
- Boas práticas de organização de código

## 🎯 Objetivo

O objetivo deste projeto é evoluir gradualmente, aplicando novos conceitos da linguagem Java e simulando funcionalidades presentes em um sistema bancário real.

Cada nova etapa será versionada no GitHub para registrar a evolução do projeto e do aprendizado.
